About AI Expense Tracker

A full-stack financial intelligence application built to solve real-world personal budgeting challenges through machine learning and conversational AI.

🎯 Problem Statement & Solution

Most personal finance apps suffer from high friction: users are forced to manually choose categories from clunky dropdowns, look only at backward-looking tables with no predictive foresight, and lack intelligent insights on where their money is actually going.

ExpenseAI solves this by combining Natural Language Processing for instant zero-friction expense logging ("spent ₹350 on fuel yesterday"), Least-Squares Linear Regression ML to forecast future expenditures, and Interactive Chart.js Visualizations with 5-state UX feedback.

🛠️ Technology Stack & Architecture

🐍 Backend & API
Python 3.11+, Flask REST architecture, Werkzeug Security for password hashing, and session management.
🗄️ Database Layer
SQLite 3 with ACID-compliant relational schema, foreign key cascades, and automated schema migrations.
🤖 AI & ML Engine
Least-squares linear regression model, R² goodness-of-fit confidence scoring, regex NLP intent classification.
🎨 Frontend & UX
Vanilla CSS custom property tokens, Glassmorphism, Chart.js 4.4, responsive drawer, and 5-state UX design.
